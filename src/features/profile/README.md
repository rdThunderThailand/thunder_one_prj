# profile

The logged-in user's own profile page (`/profile`) — new 2026-09-16, part of the shell redesign matching the coordinating session's mockup (Topbar/Sidebar restyle, this page, `account-security`, a Change Password flow). Reached only from `UserMenu`'s "โปรไฟล์ของฉัน"/"การตั้งค่าส่วนบุคคล" items — not in the sidebar (the mockup doesn't list it there). Nests under a shell-level route (`(dashboard)/(shell)/profile`), not any App's `(application)` tree, since it's account-level, not workspace-level.

> **Real for reading, narrow for writing.** Core's `GET /api/core/v1/me` returns everything this page shows: email, names (EN/TH), date of birth, phone, display name, avatar URL, preferred language, timezone, role. Writing is narrower: `PATCH /api/core/v1/users/{id}` only accepts `first_name`/`last_name`/`first_name_th`/`last_name_th`/`date_of_birth`/`phone`; `display_name` and `timezone` are real to *read* but have **no write route** in Core, and `preferred_language` is changed only through the shell's language switch. The avatar has its own upload route. See `services/profile-api.ts`'s own header comment.

- `services/profile-api.ts` — `getMyProfile(token)` (server-only, `coreGet("/me", token)`), `updateUserProfile(userId, input)` (client-safe via `/api/proxy`; also reused by `people/personnel`'s `EditPersonnelModal` for HR editing another user), `getMyMembership` (the caller's own member row), `uploadMyAvatar`/`removeMyAvatar` (`POST`/`DELETE /me/avatar`), and `changePassword` (`PATCH /me/password`, used by `account-security`).
- `components/ProfilePage.tsx` — avatar/name/role/org header + 3 tabs (ข้อมูลส่วนตัว/การทำงานในองค์กร/ช่องทางการติดต่อ). "ข้อมูลส่วนตัว" is editable via `EditProfileModal` (EN/TH names and date of birth); "การทำงานในองค์กร" shows org/role/department plus membership fields and is managed by HR, not editable here; "ช่องทางการติดต่อ" shows the personal mobile phone (editable via `EditPhoneModal`), while office phone/extension/address and LINE are static "no data" rows. "รูปแบบการแสดงผล" (ภาษา/timezone) reads real values but its "แก้ไข" button is disabled — Core has no write path for it.
- `components/EditProfileModal.tsx`, `EditPhoneModal.tsx` — `Modal`-based edit forms that call `updateUserProfile`.
- `components/ProfileAvatarEditor.tsx` — avatar upload/remove (`jpeg`/`png`/`webp`, ≤ 2 MB, checked client-side first).
- `components/AddContactChannelModal.tsx` — the mockup's add-channel form; Core has no multi-channel contact model, so submitting only shows a "not available yet" state.
- Not built: bio/"เกี่ยวกับฉัน" (no such column exposed by `/me`; the edit button is disabled).
