# Browser checklist — Create Playlist Step 1

**คู่กับ:** `docs/playlists/plan-create-playlist-step1.md` (Phase 1.1 + 1.3)
**ครอบคลุม:** AC 26 (ของใหม่) และ AC 1, 3, 18, 19, 20, 23, 25 (code-correct แต่ยังไม่เคยเห็นจริง)
**วันที่:** 2026-08-17 · branch `feat/playlist`

## เตรียม

```bash
pnpm dev            # อย่าใช้ npm — pnpm เท่านั้น
```

เปิด `http://localhost:3000/playlists` ล็อกอินให้เรียบร้อย
ก่อนเริ่มแต่ละบล็อก: เปิด DevTools → Application → Local Storage → ลบคีย์ **`thunderone.playlists.create-draft.v2`** เพื่อเริ่มจากศูนย์
เปิดแท็บ Network ค้างไว้ตลอด (ใช้ยืนยัน AC 2 / 23)

## A. AC 26 — Unsaved-changes confirmation (ของที่เพิ่งแก้)

| # | ทำ | ผลที่คาดหวัง | ผ่าน? |
|---|---|---|---|
| A1 | เข้า `/playlists/create` แล้วกด **Back: Playlists** ทันที (ยังไม่พิมพ์อะไร) | ออกไป `/playlists` เลย **ไม่มี** การ์ดถาม | |
| A2 | เข้าใหม่ พิมพ์ชื่อ `test-guard` แล้วกด **Back: Playlists** | มีการ์ดขอบเหลืองโผล่เหนือ stepper ข้อความว่า "ยังไม่ได้บันทึกร่างนี้ลงระบบ…" มีปุ่ม **อยู่ต่อ** / **ออกโดยไม่บันทึก** และ **ยังอยู่หน้าเดิม** | |
| A3 | กด **อยู่ต่อ** | การ์ดหาย ยังอยู่หน้าเดิม ชื่อที่พิมพ์ยังอยู่ครบ | |
| A4 | กด Back อีกครั้ง → กด **ออกโดยไม่บันทึก** | ไปที่ `/playlists` | |
| A5 | กลับเข้า `/playlists/create` | แบนเนอร์ "มี draft ที่ทำค้างไว้อยู่" โผล่ (ยืนยันว่าร่างไม่ได้หาย แค่ไม่ได้ถูกบันทึกขึ้นระบบ) | |
| A6 | อยู่ step 2 แล้วกด **Back** | ถอยไป step 1 เฉยๆ **ไม่มี** การ์ดถาม (ตั้งใจ — ถอย step ไม่ทำอะไรหาย) | |
| A7 | พิมพ์ชื่อค้างไว้แล้ว **กด F5 refresh** | ไม่มี native dialog "Leave site?" และหลังโหลดเสร็จร่างยังอยู่ครบ | |

> A7 คือจุดที่ตั้งใจ **ไม่** ใส่ `beforeunload` — ถ้าคุณยังอยากได้ native prompt ตรงนี้ บอกได้ เพิ่ม ~5 บรรทัด แต่มันจะเตือนทั้งที่ไม่มีอะไรหาย

## B. AC 1, 3 — เข้าหน้าได้ และ stepper ถูกลำดับ

| # | ทำ | ผลที่คาดหวัง | ผ่าน? |

## C. AC 2, 19, 18 — เปิดหน้าเปล่าๆ ไม่สร้าง record · Summary ตรงกับฟอร์ม

| # | ทำ | ผลที่คาดหวัง | ผ่าน? |
|---|---|---|---|
| C1 | ล้าง Network log แล้วเปิด `/playlists/create` ใหม่ | มีแต่ GET (campaigns / tags / media assets) **ไม่มี POST/PUT ไปสร้าง playlist** (AC 2) | |
| C2 | ดูการ์ด Summary ด้านขวาตอนยังไม่กรอกอะไร | **Items = 0** และ **Duration = 00:00:00** (AC 19) | |
| C3 | พิมพ์ชื่อ, เลือก Campaign, เลือก Tags, ใส่ Description | Summary ขวาอัปเดตตามทันทีทุกช่อง ค่าตรงกับที่พิมพ์เป๊ะ (AC 18) | |
| C4 | ลบชื่อออกให้ว่าง | Summary กลับไปสถานะว่างตาม ไม่ค้างค่าเดิม | |

## D. AC 20, 23 — Save as Draft และกันกดซ้ำ

| # | ทำ | ผลที่คาดหวัง | ผ่าน? |
|---|---|---|---|
| D1 | ล้างร่าง เข้าหน้าใหม่ ไม่กรอกอะไร กด **Save Draft** | การ์ดแดง "กรุณากรอกชื่อ playlist ก่อนบันทึกร่าง" ไม่มี request ออก (AC 20) | |
| D2 | พิมพ์ชื่ออย่างเดียว (Campaign/Description ว่าง) กด **Save Draft** | toast "บันทึกร่างแล้ว" — ยอมให้ข้อมูลไม่ครบ (AC 20) | |
| D3 | ดู Network ของ D2 | มี request สร้าง 1 ครั้ง จด **playlist id** ที่ได้กลับมาไว้ | |
| D4 | กด **Save Draft** ซ้ำอีก 3 ครั้งรัวๆ | ไม่เกิด playlist ใหม่ — id เดิม เป็น update ไม่ใช่ create (AC 23) | |
| D5 | เปิด `/playlists` ดูรายการ | เห็นชื่อนั้น **แถวเดียว** ไม่ซ้ำ (AC 23) | |
| D6 | กลับเข้า wizard กด **Next** รัวๆ 3 ครั้ง | ไปแค่ step 2 ไม่มี request สร้าง playlist ออกไปเลย (Next เป็น local-only ตาม ADR 0014) | |
