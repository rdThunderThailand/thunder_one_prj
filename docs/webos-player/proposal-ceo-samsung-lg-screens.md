# ข้อเสนอ: ให้ Thunder One เล่นบนจอ Samsung และ LG

**เสนอ:** CEO · **จัดทำ:** ทีม Thunder One · **วันที่:** 13 พ.ย. 2026 (ปรับจากฉบับ 11 พ.ย.) · **สถานะ:** ร่างเพื่อขอตัดสินใจ

---

## สรุปสำหรับผู้บริหาร (อ่านแค่ส่วนนี้ก็พอ)

- **เป้าหมาย:** ติดจอ Samsung หรือ LG แล้วจัดการสื่อจาก Thunder One ได้ทันที เหมือนที่ใช้อยู่ทุกวันนี้ ไม่ต้องมีกล่องเสริม
- **วันนี้ยังทำไม่ได้** เพราะโปรแกรมเล่นสื่อบนจอ (player) ที่เรามีรองรับแค่ Windows และ Android ส่วนจอ signage ของ Samsung กับ LG ใช้ระบบปฏิบัติการของตัวเอง (Tizen และ webOS)
- **ข้อดีคือหลังบ้านพร้อมแล้ว** ระบบจัดการสื่อ ตารางออกอากาศ รายงานการเล่น และระบบอัปเดตโปรแกรมใช้ของเดิมได้ทั้งหมด งานที่ขาดมีชิ้นเดียว คือ**แอปที่ติดตั้งบนจอ**
- **ข้อเสนอ:**
  1. ลูกค้าที่ต้องการใช้ตอนนี้ให้ใช้กล่อง Android ไปก่อน
  2. ทดลองบนจอ LG ที่เรามีอยู่ 2 วัน
  3. ถ้าผลทดลองผ่าน ทำแอปสำหรับ LG ก่อน แล้วค่อยต่อด้วย Samsung
- **ระยะเวลาโดยประมาณ:** LG ใช้งานได้ภายในราว 1.5–2 เดือน และ Samsung อีกราว 1 เดือน (ประมาณจากประสบการณ์ ยังไม่ได้วัดจริง)

---

## 1. โจทย์

| ต้องการ | หมายความว่า |
|---|---|
| ติดได้ทั่วถึง | ใช้ได้กับจอ signage รุ่นธุรกิจของทั้ง Samsung และ LG |
| ไม่มีกล่องเสริม | แอปต้องรันบนตัวจอเอง |
| จัดการสื่อง่าย | ทั้งเราและลูกค้าทำงานใน Thunder One ที่เดิม ไม่ต้องเรียนระบบใหม่ |
| ดูแลง่าย | อัปเดตแอปจากระยะไกล รู้ว่าจอไหนออนไลน์อยู่ และรู้ว่าจอเล่นอะไรไปแล้ว |

**ข้อจำกัดสำคัญ:** ต้องเป็น**จอ signage รุ่นธุรกิจ** เช่น LG UH5Q ที่เรามีจอทดสอบ 43UH5Q-E อยู่แล้ว หรือ Samsung รุ่น SSSP
**ทีวีบ้านไม่เหมาะ** เพราะลงแอปของเราได้แค่ในโหมดนักพัฒนา ซึ่งหมดอายุเป็นระยะแล้วแอปจะถูกลบทิ้ง และทีวีบ้านไม่ได้ออกแบบมาให้เปิดตลอด 24 ชั่วโมง

## 2. แนวทางที่เป็นไปได้

### แนวทาง A — เสียบกล่อง Android ที่จอ

ใช้กล่อง Android TV เสียบช่อง HDMI แล้วลงแอป Thunder One ตัวที่ใช้อยู่แล้ว

| ➕ ข้อดี | ➖ ข้อเสีย |
|---|---|
| **ใช้ได้วันนี้เลย** ไม่ต้องพัฒนาอะไรเพิ่ม | มีกล่องเพิ่ม 1 ชิ้นต่อจอ ทั้งเป็นค่าใช้จ่ายและเป็นจุดที่เสียได้อีกจุด |
| ใช้ได้กับจอทุกยี่ห้อ รวมทีวีบ้าน | สายไฟ สาย HDMI และการเปิดเครื่องพร้อมจอต้องตั้งค่าเองทีละจอ |
| ทุกฟีเจอร์ของ Thunder One ใช้ได้ครบ | **ไม่ตรงกับโจทย์ "ไม่มีกล่องเสริม"** |

### แนวทาง B — ทำแอปของเราเองติดตั้งบนจอ (แนะนำ)

เขียนแอป player ด้วยเทคโนโลยีเว็บ แล้วแพ็กเป็นแอปของจอแต่ละยี่ห้อ ได้แก่ `.ipk` สำหรับ LG และ `.wgt` สำหรับ Samsung
ช่างติดตั้งตั้งค่าในเมนูของจอให้ชี้ไปที่ server ของเรา**ครั้งเดียว** จากนั้นจอจะดาวน์โหลดแอปมาติดตั้งเองและเปิดแอปทุกครั้งที่บูต

| ➕ ข้อดี | ➖ ข้อเสีย |
|---|---|
| **ตรงโจทย์ทุกข้อ:** ไม่มีกล่อง และจัดการทุกอย่างใน Thunder One | ต้องลงแรงพัฒนา คาดว่าประมาณ 1.5–2 เดือนสำหรับ LG |
| ใช้หลังบ้านเดิมทั้งหมด ทั้งตาราง รายงาน และระบบอัปเดตแอป | ทีมเรายังไม่เคยทำแอปบนจอ ต้องเรียนรู้ระบบของแต่ละยี่ห้อ |
| เป็นวิธีมาตรฐานที่ผู้ให้บริการ signage รายใหญ่ใช้กัน เช่น Appspace, NowSignage, Pickcel | แต่ละยี่ห้อมีส่วนเล่นวิดีโอและเก็บไฟล์คนละแบบ ต้องเขียนส่วนนั้นแยกกัน |
| ไม่มีค่า license รายจอให้บริษัทอื่น | ต้องทดสอบเปิดเครื่องทิ้งไว้นานๆ ให้แน่ใจว่าเล่นได้ 24/7 โดยไม่ค้าง |
| Samsung ใช้ Chromium และมีเครื่องมือ debug แอปบนจอจริงจากระยะไกล ทำให้พัฒนาง่ายขึ้น | เอกสารนักพัฒนาของ LG ต้องเข้าผ่าน LG B2B Partner Portal ซึ่งต้องสมัครก่อน |
| เป็นของเราเอง จึงเพิ่มฟีเจอร์ได้ตามแผน Thunder One | ยังมี 2–3 เรื่องที่ต้องทดลองบนจอจริงก่อน (ดูหัวข้อ 4) |

### แนวทาง C — ใช้ CMS ของยี่ห้อจอ (LG SuperSign / Samsung MagicInfo, VXT)

| ➕ ข้อดี | ➖ ข้อเสีย |
|---|---|
| ใช้ได้ทันทีและผู้ผลิตจอดูแลให้ | **ไม่ได้ใช้ Thunder One เลย** ลูกค้าต้องใช้ระบบของ LG หรือ Samsung แทน |
| รองรับจอของยี่ห้อตัวเองได้ดีที่สุด | ต้องมี 2 ระบบสำหรับ 2 ยี่ห้อ และจัดการจากที่เดียวไม่ได้ |
| | มีค่า license **ต่อจอต่อเดือนหรือปี** จ่ายให้ผู้ผลิตจอ |
| | ฟีเจอร์เฉพาะของเรา เช่นตารางออกอากาศ รายงานการเล่น และ workflow อนุมัติ หายไปทั้งหมด |

แนวทางนี้คือการ**ใช้สินค้าของคู่แข่งแทนของเรา** จึงไม่แนะนำ เว้นแต่จะเปลี่ยนไปเป็นตัวแทนขายระบบของ LG หรือ Samsung

### แนวทาง D — ให้จอเปิดหน้าเว็บ (ไม่ต้องติดตั้งแอป)

ตั้งค่าให้จอเปิด URL ของเว็บ player ที่วางไว้บน server ของเรา

| ➕ ข้อดี | ➖ ข้อเสีย |
|---|---|
| พัฒนาง่ายที่สุดในกลุ่มที่ไม่ต้องใช้กล่อง | **ถ้าอินเทอร์เน็ตล่มตอนเปิดจอ จะขึ้นจอดำ** |
| อัปเดตครั้งเดียวได้ทุกจอ | เก็บวิดีโอขนาดใหญ่ไว้เล่นแบบออฟไลน์ได้ไม่ดี |
| | ควบคุมจอ เช่นตั้งเวลาเปิดปิด ได้น้อยกว่าแนวทาง B |

แนวทางนี้เหมาะเป็นส่วนเสริมของแนวทาง B มากกว่าใช้เดี่ยวๆ

### แนวทาง E — ใช้แพลตฟอร์มกลางของบริษัทอื่น (เช่น signageOS)

มีบริษัทที่รับทำชั้นกลางให้ เราเขียนแอปครั้งเดียว แล้วชั้นกลางนั้นรันได้ทั้ง Samsung, LG, Android และ Windows

| ➕ ข้อดี | ➖ ข้อเสีย |
|---|---|
| เขียนครั้งเดียวได้หลายยี่ห้อ จึงอาจออกสู่ตลาดได้เร็วกว่า | มี**ค่าบริการต่อจอ**ตลอดไป (ยังไม่ได้ขอราคา) |
| ผู้ให้บริการดูแลความต่างของจอแต่ละรุ่นให้ | ระบบของเราจะต้องพึ่งบริษัทอื่น ถ้าเขาขึ้นราคาหรือเลิกบริการก็กระทบเรา |
| | ยังไม่ได้ประเมินอย่างละเอียด |

### ระบบดูแลฮาร์ดแวร์ของแต่ละยี่ห้อ (ใช้ร่วมกับแนวทาง B ได้)

ทั้งสองยี่ห้อมีระบบดูแลตัวจอจากระยะไกลของตัวเอง ระบบเหล่านี้**ไม่ได้แข่งกับ Thunder One** เพราะแบ่งหน้าที่กันชัดเจน
Thunder One ดูแลสื่อและตารางออกอากาศ ส่วนระบบของยี่ห้อดูแลฮาร์ดแวร์
ในเฟสแรกเราจึงไม่ต้องสร้างระบบดูแลฮาร์ดแวร์เอง

| ยี่ห้อ | ระบบ | ทำอะไรได้ |
|---|---|---|
| LG | **LG ConnectedCare** (ผ่าน LG Business Cloud, มีค่า license) | ดูสถานะไฟ อุณหภูมิ และเครือข่ายแบบ real-time, เปิดปิดจอจากระยะไกล, แจ้งเตือนทางอีเมล, รายงานพลังงาน |
| Samsung | **Tizen Business Manager Portal** | ลงทะเบียนจอ ตั้งค่าแบบ Zero Touch และจัดการจอ ซึ่งอาจใช้ติดตั้งแอปของเราลงหลายจอพร้อมกันได้ (ยังไม่ได้ยืนยันรายละเอียด) |

## 4. ความเสี่ยงของแนวทาง B และวิธีลดความเสี่ยง

| ความเสี่ยง | วิธีลด |
|---|---|
| ยังไม่รู้แน่ว่าจอ LG ดาวน์โหลดวิดีโอเก็บไว้ในเครื่องแล้วเล่นตอนไม่มีเน็ตได้ดีแค่ไหน | **ทดลองบนจอจริง 2 วันก่อนเริ่มพัฒนา** ถ้าไม่ผ่านจะหยุดทันที เสียไปแค่ 2 วัน |
| ยังไม่รู้ว่า LG สั่งอัปเดตแอปจากระยะไกลได้หรือไม่ | ทดลองในรอบเดียวกัน ถ้าทำไม่ได้มีทางสำรอง คือให้จอดึงแอปเวอร์ชันใหม่จาก server เอง ส่วน Samsung ยืนยันจากเอกสารแล้วว่าทำได้ |
| ทีมยังไม่มีประสบการณ์ทำแอปบนจอ | เริ่มจากยี่ห้อเดียว (LG ที่มีจออยู่แล้ว) และฟีเจอร์พื้นฐานก่อน ระบบเดิมของเรามีกลไกกันไม่ให้ส่งฟีเจอร์ที่จอยังไม่รองรับลงไป จึงทำทีละขั้นได้อย่างปลอดภัย |
| เปิดเครื่องทิ้งไว้นานแล้วอาจค้าง | เผื่อเวลาทดสอบเปิดต่อเนื่อง 1–2 สัปดาห์ และตั้งสื่อสำรองในตัวจอ (ฟีเจอร์ Fail-over) ไว้แสดงแทนจอดำเมื่อแอปมีปัญหา |
| จอ Samsung บางรุ่นอาจต้องใช้ใบรับรองระดับพาร์ทเนอร์ | ตรวจสอบก่อนเริ่มทำ Samsung และสมัครโปรแกรมพาร์ทเนอร์ถ้าจำเป็น |
| **ใหม่:** ลูกค้า LG ที่ใช้ **ConnectedCare Premium** อาจเปิดฟีเจอร์ "จำกัดการรันแอปที่ไม่ได้รับอนุญาต" ซึ่งอาจบล็อกแอปของเรา | ระบุไว้ในคู่มือติดตั้งว่าต้องเพิ่มแอปเราเข้า whitelist และสอบถาม LG ว่าทำได้อย่างไร |
| เอกสาร SDK ของ LG อยู่หลังระบบสมาชิก | สมัคร LG B2B Partner Portal ก่อนเริ่มทดลอง |

## 5. ข้อเสนอและลำดับงาน

| ระยะ | ทำอะไร | ระยะเวลา (ประมาณ) | ผลลัพธ์ |
|---|---|---|---|
| **0. ตอนนี้** | ลูกค้าที่รอไม่ได้ใช้กล่อง Android ไปก่อน (แนวทาง A) | — | ขายและติดตั้งได้ทันที |
| **1. ทดลอง** | ทดสอบ 6 ประเด็นบนจอ LG 43UH5Q-E | 2 วัน | รู้ว่าแนวทาง B ใช้ได้จริงหรือไม่ ก่อนลงทุนเต็มที่ |
| **2. LG รุ่นแรก** | แอปที่เล่น playlist ตามตาราง ส่งสถานะจอ รายงานการเล่น และอัปเดตจากระยะไกลได้ | 3–5 สัปดาห์ + ทดสอบ 1–2 สัปดาห์ | ลูกค้าที่ใช้จอ LG เลิกใช้กล่องได้ |
| **3. Samsung** | ใช้โค้ดหลักชุดเดิม เขียนเพิ่มเฉพาะส่วนที่ต่างกัน | ~3–4 สัปดาห์ | ครอบคลุมทั้ง 2 ยี่ห้อ |
| **4. ฟีเจอร์ขั้นสูง** | แบ่งจอหลายช่อง เล่นพร้อมกันหลายจอ และเอฟเฟกต์เปลี่ยนสื่อ | แล้วแต่ผลทดลอง | ใช้ได้เท่ากับ player ตัวปัจจุบัน |

ระยะเวลาทั้งหมดเป็นการประมาณสำหรับนักพัฒนา 1 คน ระยะ 1 จะทำให้ตัวเลขแม่นขึ้น

## 6. สิ่งที่ขอให้ตัดสินใจ

1. **อนุมัติแนวทาง B** เป็นทางหลัก โดยใช้ A เป็นทางชั่วคราวระหว่างพัฒนา
2. **ยืนยันลำดับยี่ห้อ** ว่าให้ทำ LG ก่อน (เรามีจอทดสอบแล้ว) หรือจะให้ Samsung ขึ้นก่อน ถ้าลูกค้าในมือส่วนใหญ่ใช้ Samsung
   ข้อมูลล่าสุดชี้ว่า**ฝั่ง Samsung ความเสี่ยงทางเทคนิคต่ำกว่า** เพราะเอกสารเปิดให้อ่าน และยืนยันแล้วว่าเก็บไฟล์ในเครื่องกับ debug บนจอจริงได้ แต่ต้องซื้อจอทดสอบก่อน
3. **งบซื้อจอ Samsung signage 1 เครื่อง** สำหรับทดสอบในระยะ 3
4. **คนรับผิดชอบ:** นักพัฒนา 1 คนเต็มเวลา ช่วงระยะ 2–3
5. **ต้องการให้ขอราคาแนวทาง E (signageOS) ไว้เปรียบเทียบด้วยหรือไม่**

### ภาคผนวก — สิ่งที่ยืนยันแล้วและยังไม่ได้ยืนยัน

**ยืนยันแล้ว**
- จอ LG 43UH5Q-E เป็นจอ signage ที่ใช้ webOS 8.0 มีหน่วยประมวลผลในตัว และ LG ระบุว่า "ไม่ต้องใช้ media player แยก"
- LG ติดตั้งแอปของบริษัทอื่นผ่าน USB หรือ SI Server ได้
- Samsung ติดตั้งและอัปเดตแอปผ่าน URL Launcher ได้
- ผู้ให้บริการ signage หลายรายใช้วิธีเดียวกับแนวทาง B
- LG SuperSign Cloud คิดค่า license ต่อจอ
- Samsung signage ใช้เว็บเอนจิน Chromium มี Download API และ Filesystem API สำหรับเก็บไฟล์ในเครื่อง มี AVPlay สำหรับเล่นวิดีโอ และมี Remote Web Inspector สำหรับ debug บนจอจริง
- Samsung มีช่องทางเผยแพร่แอปสำหรับ signage ผ่าน Seller Office นอกจาก URL Launcher และ USB
- LG ConnectedCare Premium มีฟีเจอร์จำกัดการรันแอปที่ไม่ได้รับอนุญาต

**ยังไม่ได้ยืนยัน (ต้องทดลองหรือสอบถามเพิ่ม)**
- LG อัปเดตแอปตัวเองได้หรือไม่ และเก็บวิดีโอในเครื่องได้มากแค่ไหน
- Tizen Business Manager Portal ติดตั้งแอปของเราลงหลายจอพร้อมกันได้หรือไม่
- Samsung ต้องใช้ใบรับรองพาร์ทเนอร์หรือไม่
- ราคาจริงของ SuperSign, MagicInfo และ signageOS ในไทย
- ระยะเวลาพัฒนาทั้งหมด ซึ่งเป็นค่าประมาณ
