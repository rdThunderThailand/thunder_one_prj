# Create Publication Program viewport plan

## Goal

Make the Step 3 Program workspace readable as one continuous page while keeping
the destination data and summary visible.

## Changes

1. Let the dashboard page own vertical scrolling instead of individual panels.
2. Compact the Where to Play segmented control and destination controls without
   removing channel or group data.
3. Constrain Program Summary values with native `title` tooltips and truncation.

## Non-goal

Do not lock the viewport or introduce nested panel scrolling.
