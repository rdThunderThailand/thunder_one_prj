### R2 — กำหนดการที่ไม่เหลือรอบเล่นแล้ว (แทน A7)

**ก่อนเริ่มจดเวลาปัจจุบัน (ICT)** ข้อ R2.2–R2.5 ต้องใช้ช่วงเวลาเล่นที่จบไปแล้วในวันนี้ ตัวอย่างใช้ 00:00–01:00 ถ้าทดสอบก่อนตี 1 ให้เปลี่ยนเป็นช่วงอื่นที่จบไปแล้ว

**เตรียม:** Programs → Create Program → เลือกแบบ Playlist → `zz-uat2-playlist-02` → Next ไปขั้น 2 ตั้งชื่อ Program เป็น `zz-uat3-r2` → Next ไปขั้น 3 → เลือก Channel `testwindow 2` → เลื่อนลงไปที่ When to Play → กด **Edit schedule**

| ID | ขั้นตอน | ผลที่คาด | ผล | หมายเหตุ |
|---|---|---|---|---|
| R2.1 | ในกล่อง Edit Schedule เลือก preset **Date range** → Start date = วันนี้ → ติ๊ก Set end date → End date = **วันนี้** → เอาติ๊ก All day ออก → Start time `00:00` End time `01:00` | ใต้ช่อง End date ขึ้นข้อความสีแดง **"ช่วงเวลาเล่นสุดท้ายผ่านไปแล้ว กรุณาแก้วันหรือเวลาสิ้นสุด"** · ปุ่ม **Apply Schedule กดไม่ได้** · Schedule Preview แสดงแค่วันนี้ | | เคสเดียวกับ A7 ของรอบ 2 |
| R2.2 | เปลี่ยน End time เป็น `23:00` (ยังเป็นวันนี้) | ข้อความสีแดงหายไป Apply Schedule กดได้ | | ตรวจว่ากฎไม่เข้มเกินไป |
| R2.3 | เปลี่ยน End time กลับเป็น `01:00` → เปลี่ยน End date เป็น**พรุ่งนี้** | ข้อความหาย Apply กดได้ (พรุ่งนี้ยังมีรอบเล่น 00:00–01:00) | | |
| R2.4 | เปลี่ยน End date กลับเป็นวันนี้ → ลองเปลี่ยน preset เป็น **Every day**, **Weekdays** (ถ้าวันนี้เป็นวันธรรมดา), **Custom days** (ติ๊กวันนี้) และ **Monthly** (เลือกวันที่ของวันนี้) ทีละแบบ ใช้ช่วง 00:00–01:00 และ End date = วันนี้ทุกครั้ง | ทุกแบบขึ้นข้อความเดียวกับ R2.1 และ Apply กดไม่ได้ | | ติ๊ก Set end date แล้ว preset เปลี่ยนเป็น Date range หรือ Custom days เอง ถือว่าปกติ ให้ดูแค่ข้อความและปุ่ม · ถ้า preset ไหนไม่มีช่อง End date ให้ข้ามแบบนั้นและจดไว้ |
| R2.5 | เลือก preset **One-time only** → วันที่ = วันนี้ → 00:00–01:00 | ขึ้นข้อความภาษาไทย **"ช่วงเวลาเล่นของวันนี้ผ่านไปแล้ว"** และ Apply กดไม่ได้ | | |
| R2.6 | **กรณีค้างหน้า Review จนเลยเวลา:** ตั้ง preset **Date range** วันเริ่ม/วันจบ = วันนี้ · Start time = เวลาปัจจุบันปัดลง · End time = **อีก 3 นาทีข้างหน้า** → Apply Schedule → Next ไปขั้น 4 และ 5 → **รอจนเลยเวลาจบอย่างน้อย 1 นาที** → กด **Publish Now** | ระบบ**ไม่ส่ง** และขึ้นข้อความภาษาไทยว่า Program นี้สิ้นสุดเมื่อ `<วัน เวลา>` ซึ่งผ่านไปแล้ว พร้อมคำแนะนำ · ไปที่ Programs ต้อง**ไม่มี** `zz-uat3-r2` ที่สถานะ Active หรือ Scheduled | | ถ้าระบบ Publish ไปแล้ว ให้จดเวลา + URL แล้วแจ้งทีม dev ให้ unpublish ทันที |
| R2.7 | กลับไปขั้น 3 → Edit schedule → ตั้ง End time ให้เป็นเวลาในอนาคต หรือเปลี่ยนเป็น Every day ไม่มีวันจบ → Apply → ไปขั้น 5 → **Save draft** (ไม่ Publish) | บันทึก Draft ได้ ไม่มีข้อความ error | | |

## Known gaps (ไม่ต้องเปิด issue ใหม่)

ทุกข้อใน "Known gaps" ของ `uat-v1-checklist.md` ยังใช้ได้ และเพิ่ม:

- **Core ไม่ตรวจกำหนดการที่ไม่เหลือรอบเล่น:** การตรวจใน R2 อยู่ที่หน้าเว็บ ถ้าส่งผ่าน API ตรงจะยังรับได้ (แก้ฝั่ง Core นอก v1.0)
- **ข้อความ validation ของกำหนดการเป็นภาษาไทยเสมอ** ไม่เปลี่ยนตามภาษาของ UI
- **กด Publish to Channel ตอนกำลังแก้ชื่อเป็นชื่อว่าง:** กล่อง "มีการแก้ไขที่ยังไม่บันทึก" ขึ้นก่อน แล้วกด Save แล้วไปต่อ จึงจะเห็นข้อความให้ใส่ชื่อ
