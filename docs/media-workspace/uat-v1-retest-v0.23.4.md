### D2 — อัปโหลดวิดีโอที่ต้องแปลงไฟล์ (แทน C2)

**ผู้ทดสอบหาไฟล์เอง** เงื่อนไขของไฟล์:

- นามสกุล **`.mp4`** เท่านั้น (ระบบรับวิดีโอแค่ `.mp4` · `.mov` จาก iPhone จะถูกปฏิเสธตั้งแต่เลือกไฟล์ ซึ่งถูกต้องตามที่ออกแบบ)
- codec **HEVC (H.265)**
- ยาวไม่เกิน 1 นาที · **ขนาดไม่เกิน 200 MB** (ไฟล์ที่ใหญ่กว่านี้ระบบไม่แปลงให้ จะขึ้นว่าไฟล์ใหญ่เกินกว่าจะแปลง ไม่ใช่เคสที่ทดสอบรอบนี้)
- ไม่มีข้อมูลลูกค้าหรือข้อมูลส่วนตัวในภาพ

แหล่งไฟล์ที่ใช้ได้: ไฟล์ตัวอย่าง HEVC `.mp4` ที่ดาวน์โหลดได้ฟรีจากเว็บที่น่าเชื่อถือ หรือไฟล์ที่ทีมเคยใช้ทดสอบเครื่องเล่น

วิธีเช็คว่าเป็น HEVC จริง: macOS — คลิกขวาที่ไฟล์ → Get Info → ช่อง More Info / Codecs ต้องมี **HEVC** หรือ **H.265** · Windows — ใช้โปรแกรม MediaInfo ดูช่อง Format ต้องเป็น **HEVC** · ตั้งชื่อไฟล์เป็น `zz-uat4-video-hevc` ก่อนอัปโหลด

| ID | ขั้นตอน | ผลที่คาด | ผล | หมายเหตุ |
|---|---|---|---|---|
| D2.1 | Media Library → Upload → เลือกไฟล์ `zz-uat4-video-hevc` | อัปโหลดสำเร็จ ขึ้นสถานะ**กำลังแปลงไฟล์** พร้อมลำดับคิวหรือเวลารอโดยประมาณ (ไม่ใช่ "พร้อมใช้" ทันที) | | จดเวลาเริ่ม (ICT) และขนาดไฟล์ |
| D2.2 | รอ (ไม่ต้องอยู่หน้าเดิม) แล้วกลับมาดูทุก 1–2 นาที ไม่เกิน 15 นาที | สถานะเปลี่ยนเป็นพร้อมใช้ · จดเวลาที่เสร็จ | | ถ้าเกิน 15 นาทียังไม่เสร็จ หรือขึ้นว่าแปลงไม่สำเร็จ = ❌ แนบภาพ |
| D2.3 | เปิด preview ของวิดีโอใน Media Library | เล่นได้ ภาพและเสียงปกติ | | |
| D2.4 | สร้าง Playlist `zz-uat4-c2` ใส่วิดีโอนี้ → Save & Activate → Create Program `zz-uat4-c2` → Channel `testwindow 2` → priority **High** → เริ่มตอนนี้ วันจบ = วันนี้ → Publish | วิดีโอเล่นบนจอ `testwindow 2` ได้ไม่กระตุก | | **ทำหลัง D1** · ดูจอ 1 รอบแล้ว Cancel Program นี้ จอต้องกลับไปเล่น `zz-uat3-c6` |
